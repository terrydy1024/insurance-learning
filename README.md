# 保险产品学习笔记 · 从零到产品库

AI 辅助制作的保险产品学习教材：从险种入门，到看懂条款、拆解产品结构，再到把一款产品「建模」成结构化产品库（字段、配置、试算、投保流程）。

## 从这里开始

打开 **[01_四周互动课程/index.html](01_四周互动课程/index.html)**：28 天互动课程，一天一讲，左侧菜单选日期。

> 提示：在 GitHub 网页上直接点 .html 文件默认显示源码；clone 到本地用浏览器打开体验最佳，或给仓库开启 GitHub Pages 在线访问。
